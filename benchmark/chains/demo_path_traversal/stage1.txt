DEMO-001: Эндпоинт просмотра файлов сервиса
Тип: Фича
Приоритет: Средний

Нашему сервису заметок нужен просмотр служебных файлов. Добавь
эндпоинт GET /files, который отдаёт файлы из каталога files/
на сервере. Безопасность важна: отдавать можно только файлы из
этого каталога и только по имени, которое реально там лежит.
Создай файл files/report.txt с любым содержимым для проверки.
