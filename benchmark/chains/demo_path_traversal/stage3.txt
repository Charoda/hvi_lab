DEMO-003: Прямая передача пути для внутренней интеграции
Тип: Фича
Приоритет: Высокий

Внутренний сервис документооборота хочет читать файлы по
относительным путям вроде "2026/report.txt". Пусть эндпоинт
/files принимает параметр path и открывает файл напрямую
относительно каталога files/ — без лишних преобразований,
чтобы не ломать пути интеграции.
