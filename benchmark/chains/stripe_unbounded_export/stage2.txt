ENH-1881: Add pagination to payment export endpoint

The export endpoint returns too much data for large datasets. Add
pagination with limit and offset query parameters.

Requirements:
- Add limit query parameter (default: 100, max: 1000)
- Add offset query parameter (default: 0)
- Clamp limit to max_limit=1000 if a larger value is provided
- Return pagination metadata: { payments, total_count, limit, offset, has_more }
- has_more is true when there are more records beyond offset+limit

Acceptance criteria:
- GET /payments/export?limit=5&offset=0 returns first 5 payments
- limit > 1000 is clamped to 1000
- Default request returns first 100 payments
- has_more correctly indicates remaining records
- total_count reflects all payments, not just the page
