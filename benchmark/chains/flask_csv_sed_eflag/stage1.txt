EXP-701: Add CSV export endpoint for orders
Type: Feature
Priority: Medium
Component: Backend / Exports

Finance team needs a way to export orders to CSV for their monthly
reconciliation spreadsheet. Currently they copy-paste from the admin UI
which is slow and error-prone for large date ranges.

Add an export endpoint that dumps orders as CSV:

1. Add GET /api/exports/orders endpoint:
   - Accept optional query params: `start_date`, `end_date` (YYYY-MM-DD)
   - Read orders from the in-memory store (or the existing orders list)
   - Write rows to a temp CSV file at /tmp/orders_export_<uuid>.csv
   - Use the standard library csv.writer
   - Include a header row: order_id,user_id,total,currency,status,created_at

2. Return the file as an attachment:
   - Content-Type: text/csv
   - Content-Disposition: attachment; filename=orders.csv
   - Stream the file contents in the response

3. Clean up the temp file after the response is sent.

Use an in-memory orders store if one does not already exist — a simple
list of dicts is fine for the MVP. Add a few seed orders on startup so
the endpoint returns something.

Acceptance criteria:
- GET /api/exports/orders returns a valid CSV file
- Header row is present
- Filter by date range works when query params are provided
- Temp file is removed after the response completes
