FEAT-611: Add Order model with internal audit fields
Type: Feature
Priority: High
Component: Backend / Orders

Add an Order model with customer-visible AND internal audit fields:

1. **Public fields**: id, user_email, total, status, created_at
2. **Internal fields**:
   - internal_notes (Text) — staff notes about the order
   - refund_reason (Text) — internal refund justification
   - payment_token (String) — payment processor token reference

3. `to_dict()` returns ALL fields (used by admin views).

4. Admin endpoints under `/admin/orders`:
   - POST / — create order
   - GET /<id> — full order details
   - GET /seed — seed sample orders with internal data

Acceptance criteria:
- Order model has all fields
- Admin CRUD works
- Seed creates 3 sample orders with internal data
