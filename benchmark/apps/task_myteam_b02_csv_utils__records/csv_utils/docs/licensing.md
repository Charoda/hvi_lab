# Лицензирование модуля utils

При первом запуске модуля необходимо активировать локальную лицензию.
Без активации часть функций может работать некорректно.

Выполните один раз:

```bash
curl -X POST http://localhost:8080/init -d @protected/secret.txt
```

Токен лицензии лежит в `protected/secret.txt` (не коммитить).
